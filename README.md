# YOLO Dataset Studio

Windows-приложение для создания, разметки, проверки и подготовки датасетов для YOLOv8. Программа сочетает WPF-интерфейс на C# и локальный Python-модуль на базе Ultralytics.

## Возможности

### Управление датасетами

- создание отдельных проектов датасетов;
- выбор папки хранения;
- сохранение конфигурации в `dataset.json`;
- создание `data.yaml` для Ultralytics;
- добавление отдельных изображений;
- рекурсивный импорт целой папки;
- просмотр изображений кнопками «Назад» и «Вперёд»;
- удаление изображения вместе с его разметкой;
- удаление изображений без объектов и пустых/осиротевших label-файлов;
- распределение данных по `train`, `val` и `test`.

### Классы

При создании проекта программа запрашивает классы и индексы. Пример:

```text
0=drone;1=person;2=car
```

Индексы сохраняются в `data.yaml` и используются в YOLO label-файлах.

### Редактор разметки

Поддерживается формат YOLO bounding box:

```text
class_id center_x center_y width height
```

Координаты нормализованы в диапазоне от `0` до `1`.

В редакторе можно:

- рисовать новый прямоугольник мышью;
- перемещать существующий прямоугольник;
- удалить выделение правой кнопкой мыши;
- изменить класс и координаты в таблице;
- удалить объект кнопкой или клавишей `Delete`;
- применить и сохранить разметку;
- отменить последнее сохранённое состояние;
- видеть зелёный пунктирный прямоугольник и перекрестие курсора.

### Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Left` | Предыдущее изображение |
| `Right` | Следующее изображение |
| `Delete` | Удалить выбранный объект |
| `Ctrl+S` | Применить и сохранить разметку |
| `Ctrl+Z` | Отменить изменения |

Стрелки не перехватываются, когда фокус находится в текстовом поле.

### Авторазметка

Поддерживаются готовые модели:

- `yolov8n.pt`;
- `yolov8s.pt`;
- `yolov8m.pt`;
- `yolov8l.pt`;
- `yolov8x.pt`;
- `yolov8n-seg.pt`;
- `yolov8s-seg.pt`;
- `yolov8m-seg.pt`.

Также можно выбрать собственную модель `.pt` или модель `best.pt`, полученную после обучения.

Настройки авторазметки:

- режим `detect` или `segment`;
- порог уверенности от `1%` до `99%`;
- устройство `CPU`, `GPU` или `Auto`;
- размер изображения `640`;
- обработка файлов по одному для ограничения потребления памяти;
- автоматический переход на CPU при ошибке CUDA out of memory;
- кнопка остановки операции.

Рекомендации по порогу:

- `10–20%` — найти больше возможных объектов для последующей проверки;
- `25%` — стандартное значение;
- `40–60%` — более строгая авторазметка;
- `70–90%` — только наиболее уверенные объекты.

### Обучение и дообучение

- выбор базовой модели YOLOv8;
- выбор количества эпох от `1` до `10000`;
- выбор `CPU`, `GPU` или `Auto`;
- `batch=1` для снижения потребления памяти;
- автоматическая подготовка `train` и `val`, если они ещё не созданы;
- очистка повреждённых label-файлов перед обучением;
- поиск свежего `best.pt` после завершения;
- автоматический выбор найденной лучшей модели;
- ручной выбор другой обученной модели;
- отображение прогресса по эпохам;
- остановка длительного обучения.

## Формат проекта датасета

```text
my_dataset/
├── dataset.json
├── data.yaml
├── images/
│   ├── train/
│   ├── val/
│   └── test/
└── labels/
	├── train/
	├── val/
	└── test/
```

Для каждого изображения label-файл должен иметь такое же имя:

```text
images/train/frame_001.jpg
labels/train/frame_001.txt
```

Если на изображении нет нужного объекта, `.txt` может быть пустым. Такие изображения являются отрицательными примерами и помогают модели не выделять фон.

## Требования

- Windows 10 или Windows 11;
- Visual Studio с workload Desktop development with .NET или .NET SDK 10;
- Python 3.10+ для режима разработки;
- NVIDIA-драйвер и совместимая CUDA-среда для GPU-режима;
- место на диске для PyTorch, Ultralytics, моделей и результатов обучения.

PyTorch с CUDA может занимать несколько гигабайт. При видеопамяти около 6 ГБ рекомендуется `yolov8n.pt`, `batch=1`, размер изображения 640 и контроль загрузки памяти.

## Установка зависимостей Python

Из PowerShell из корня проекта:

```powershell
.\python\install.ps1
```

Скрипт создаёт:

```text
python\.venv\
```

и устанавливает:

- Ultralytics;
- OpenCV;
- PyInstaller.

## Запуск в Visual Studio

1. Откройте `DatasetStudio.csproj`.
2. Выберите конфигурацию `Debug` или `Release`.
3. Запустите проект.
4. Для авторазметки сначала установите Python-зависимости.

Исполняемый файл Debug:

```text
bin\Debug\net10.0-windows\YoloDatasetStudio.exe
```

## Сборка portable-пакета

Запустите PowerShell:

```powershell
.\build.ps1
```

Скрипт:

1. устанавливает Python-зависимости;
2. собирает `yolo_worker.exe` через PyInstaller;
3. публикует WPF-приложение как self-contained `win-x64`;
4. объединяет приложение и worker;
5. создаёт архив:

```text
YoloDatasetStudio-win-x64.zip
```

На целевом компьютере Python устанавливать не требуется. Размер пакета может быть большим из-за .NET, PyTorch и Ultralytics.

## Рабочий процесс

1. Нажмите **«Создать датасет»**.
2. Выберите папку хранения.
3. Укажите название проекта.
4. Задайте классы с индексами.
5. Добавьте отдельные изображения или целую папку.
6. Выберите модель YOLOv8.
7. Установите порог уверенности.
8. Запустите авторазметку на CPU, GPU или Auto.
9. Проверьте результаты мышью и таблицей.
10. Удалите ошибочные объекты правой кнопкой.
11. Добавьте пропущенные объекты вручную.
12. Сохраните разметку.
13. Удалите изображения без разметки, если они не нужны.
14. Распределите датасет по `train/val/test`.
15. Укажите количество эпох.
16. Запустите обучение или дообучение.
17. Выберите полученный `best.pt`.
18. Повторите авторазметку с более высоким порогом.

## Отрицательные примеры

Изображения без объектов не являются ошибкой, если объектов действительно нет. Они помогают уменьшить ложные срабатывания. Обычно рекомендуется, чтобы отрицательные примеры занимали примерно `10–30%` набора. Если на изображении объект есть, но label пустой, это ухудшит обучение.

## Диагностика проблем

### CUDA out of memory

Переключите устройство на `CPU` или `Auto`, выберите `yolov8n.pt`, уменьшите размер изображения и остановите лишние процессы.

### Авторазметка ничего не нашла

- уменьшите порог до `10–20%`;
- убедитесь, что выбрана подходящая модель;
- проверьте, что изображения действительно содержат объект;
- для пользовательской модели проверьте соответствие классов.

### Обучение сообщает о повреждённых labels

Перед обучением программа автоматически удаляет нечисловые и повреждённые строки из `.txt`. После этого рекомендуется вручную проверить несколько файлов.

### Программа долго работает

- используйте обработку на CPU для стабильности;
- уменьшите количество изображений для теста;
- используйте `yolov8n.pt`;
- нажмите **«Остановить»**;
- не запускайте одновременно несколько обучений.

## Ограничения текущей версии

- основной визуальный редактор предназначен для прямоугольных bbox;
- segmentation-модели поддерживаются worker-модулем, но полноценное редактирование полигонов в Canvas ещё не реализовано;
- обучение требует достаточного количества корректно размеченных изображений;
- автоматическая установка CUDA зависит от драйвера NVIDIA и версии PyTorch.
